# Google雲端備份

現行功能為單向備份，不是跨裝置同步。新自動／手動備份不加密，資料與圖片可被持有檔案的人讀取；短期Google授權沿原session規則，不包含於備份。

本機交易先成功保存，從第一筆未上傳變更起計10分鐘，期間合併為最新一份快照；繼續編輯不延後期限。手動備份立即執行。只監聽本機commit，不因其他分頁刷新、點擊／捲動／切頁或到期清理重複備份。所有分頁共用上傳鎖；網路期間不持資料寫入鎖。快照包含既有資料、歷史、有效復原與必要Blob，使用原格式、驗證與期限；佇列圖片引用註冊至共用service，另持短期Web Lock阻擋其他分頁手動清理。關閉分頁自動釋放，不留下永久鎖。

成功上傳後按實際雲端時間保留最近20筆應用備份（含手動）；清理失敗顯示錯誤並保留本機，重試不重複上傳已完成的同一筆。無法辨識時間時不刪除。舊同步版本圖已退役、留在Drive；未使用本機圖不自動刪。

連接／有效授權、連線及草稿條件滿足時自動上傳。只連接的新裝置不會先上傳空白資料；有本機未備份變更時才在連接後補份目前資料。未備份revision以專用非敏感中繼欄位記住，不進備份。本機交易鎖競爭或暫時網路錯誤採限次退避，尊重Retry-After；不以無限輪詢掩蓋失敗。離線／錯誤保留本機資料及未備份標記；首次期限與資料最後變更時間存在專用非敏感中繼欄位。重新整理／重新開啟不重設期限，重新連接且期限已到時補傳最新本機資料。網站關閉、瀏覽器暫停、離線或授權失效時無法在背景保證準時上傳，回到頁面且條件恢復後補傳，不會自行開啟Google授權。啟動時僅將舊同步開關停用並移除舊專用密碼，保留舊基準中繼資料與主資料；同來源舊分頁會收到停用通知。沒有Changes輪詢、背景下載或自動還原。

設定提供雲端版本下拉選單，只顯示臺灣時間及裝置標籤；新備份以一般平台／瀏覽器標籤寫入appProperties.deviceName，沒有真實主機名稱，不保存原始User-Agent，舊檔未記錄則如實顯示。設定預載GIS，使用者一次點連接才要求Google登入／授權。所有通知集中於Google Drive標題下方，移除撤銷授權與雲端下載介面。

導覽雲端圖示仍選最新版本；設定選單可指定版本，未選則取最新。兩者共用格式／圖片／完整性驗證、對比及確認視窗。取消不寫入；確認前再次核對所選ID、大小及建立／修改時間，預設最新另核對最新ID，原子還原另核對本機revision與草稿／交易鎖。資料相同則不重寫；損毀、缺圖、權限、鎖或版本改變均保留原資料。舊加密備份在同一確認視窗輸入原密碼解密，錯誤可重試，不需下載。

測試界線：Google API與授權使用mock，實際執行Blob、加解密、IndexedDB及還原交易；不等於真實Google驗收。公開網站與Pages分開驗證。

導覽Undo旁的雲端視窗提供「登入Google／備份雲端」，沿用同一授權session及集中備份佇列。未連接時先準備GIS，再由登入按鈕同步開啟Google授權；連接後才可備份，備份按鈕上傳目前完整本機快照，不會把雲端套回本機。登入時若正在上傳則等待完成，僅排定10分鐘的待備份不阻擋載入雲端還原資訊；失敗保留本機與視窗錯誤。雲端還原交易成功立即關閉視窗，回到原觸發鈕；驗證／授權／競態／還原失敗仍留窗。取消與同資料不修改資料。

上傳前先讀最新雲端版本，比較資料最後變更時間（新備份appProperties.dataUpdatedAt），不是本次檔案建立時間；新備份另記錄去除revision／復原維護資料的內容SHA-256（dataHash），內容相同不誤報舊資料。舊雲端版本以backupTime／createdTime比較，本地舊資料以留存history／undo的時間推導，無法確認時間時如實提醒。手動上傳較舊／時間未知資料須確認，取消不寫入；確認後再核對雲端版本及本機revision。自動備份遇雲端較新時只通知並暫停，等待手動確認；不在背景彈出對話窗，也不會自動還原雲端。還原保留來源時間，本機備份匯入亦不冒充本次匯入時間。所有分頁共用上傳鎖與未備份中繼資料，完成後其他分頁不重複上傳。測試見tests/backup-delay.cjs及tests/cloud-policy.test.mjs。
