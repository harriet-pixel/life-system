# Google Drive 手動備份

現行功能為單向備份，不是跨裝置同步。只有使用者手動按下「上傳雲端」才上傳目前快照；新備份不加密，持有檔案者可讀內容。短期Google授權沿既有session規則，不進備份。連接、資料更新、Undo／Redo、focus／online、切頁、重載及還原均不自動上傳；沒有排程、背景重試、Changes輪詢、背景下載或自動還原。離線或失敗保留資料及未備份標記，須再手動點擊。啟動仍停用舊同步開關並清除舊專用密碼，保留原資料與舊基準。

只監聽本機commit標記待手動備份，無上傳期限或定時器。所有分頁共用上傳鎖；網路期間不持資料寫入鎖。快照包含既有資料、夥伴設定／出場ID／切換歷史／刪除ID、長期歷史、有效復原與必要Blob，沿用原格式及驗證。上傳期間的圖片引用註冊至共用service，持短期Web Lock阻擋其他分頁手動清理，完成或失敗釋放，不讓尚未手動備份的日常修改長期鎖住清理。

成功上傳後依實際雲端時間保留最近20筆應用備份。清理失敗顯示錯誤並保留本機，下次手動上傳重新核對；無法辨識時間不刪除。舊同步版本圖留在Drive，不自動刪除；未使用本機圖只由使用者手動清理。

設定提供雲端版本選單，只顯示臺灣時間及裝置標籤。新備份以一般平台／瀏覽器標籤存appProperties.deviceName，不記真實主機名稱或原始User-Agent；舊檔未記錄則如實顯示。設定預載GIS，使用者點連接才要求Google登入／授權。通知集中於Google Drive標題下方。

上傳前先讀最新雲端版本，比較資料最後變更時間（appProperties.dataUpdatedAt），不是本次檔案建立時間。備份保留排除revision／復原維護欄位的內容SHA-256（dataHash），內容相同不誤報舊資料。舊雲端檔回退backupTime／createdTime，本機缺時間時可由history／undoHistory推導。較舊或時間無法確認時明確確認，再檢查最新檔案身份與本機revision，變更則停止。

指定版本還原不因新增其他版本而失效；預設最新則重新核對最新身份。先下載、驗證／解密、比較，再明確確認，確認前重新檢查檔案metadata及本機revision。使用共用維護鎖及draft locks，原子取代資料；不合併角色或切換歷史。損毀、缺圖、草稿、跨分頁競態、取消均不部分覆寫。舊加密備份仍可用原密碼解密，舊備份缺夥伴欄位安全初始化。

導覽Undo旁的雲端視窗提供登入Google及手動備份，沿同一session與備份服務；未登入先準備GIS，再由登入按鈕同步開授權。備份不套用雲端。還原成功立即關窗並回焦點，錯誤留窗，取消及同資料不修改資料。認證／AI金鑰不進備份。

測試界線：Google API與授權用mock，實際執行Blob、加解密、IndexedDB、draft locks與還原交易；不等於真實Google驗收。公開網站與Pages另行驗證。

導覽雲端視窗的「備份雲端」成功後立即關窗並傳送共用通知，不再讀取／下載雲端版本；上傳錯誤保留視窗及錯誤內容，舊資料提醒及完整還原驗證維持。

2026-10-28 第二階段：導覽入口為雲端同步與備份。右上叉叉／外點／Escape不取消安全上傳；未提交的還原以epoch取消，異步驗證回來不再套用。登入／上傳／還原等寬，版本下拉只列臺灣時間與一般裝置（無瀏覽器名稱）。資料修改時間只讀可靠dataUpdatedAt，不以備份時間替代；最後成功同步時間在尚未驗收／啟用前為未記錄。手動備份不等於跨裝置已同步。還原須無本地待備份變更、完整驗證、明確確認及原子套用；設定頁中斷連線有未備份變更時須確認。本階段自動同步保持關閉。
