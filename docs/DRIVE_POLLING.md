# Google Drive前景輕量輪詢（2026-10-26）

授權、同分頁同步密碼、連線及前景有效時，每輪結束約5秒後檢查；沒有重疊或累積下一輪。隱藏（含系統鎖屏）、離線、授權失效、鎖定、未解決衝突及草稿阻擋時暫停。前景／連線恢復立即嘗試，既有執行中操作與伺服器退避仍受保護。背景不承諾計時精度。

## Drive API與請求數

正常無更新的一輪：1次GET `/drive/v3/changes`（changes.list），`spaces=appDataFolder`，只取nextPageToken、newStartPageToken及change的fileId、removed、file.id/appProperties，不取快照內容／圖片／歷史文件。超過1000筆變更時每頁多1次GET。瀏覽器可能另做CORS OPTIONS，不算額外Drive版本讀取。no-store避免快取過時變更結果。

游標首次建立／分頁接手：先1次GET `/drive/v3/changes/startPageToken`，再沿用完整版本檢查初始化記憶體索引；410失效游標同樣重新建立。這不是每5秒的工作。新領導分頁自己的索引尚未初始化，不能直接把最新游標當成已套用資料。沒有refresh token或後端新增。

有新版本時：再走既有graph（manifest及snapshot兩類files.list，有分頁則追加）、下載未快取的索引、必要時下載新加密快照／驗證與圖片、封存本機、安全套用與20筆保留清理，請求數隨新索引／分頁／清理筆數不同，不是固定1次。封存索引更新但正式版本頭未改、且本機沒改時，不下載完整快照。普通無更新輪不呼叫graph／load／prune，不上傳、建立版本、改成功時間或發布狀態重繪。

新游標只有讀完全部頁才前移；新變更標記在完整檢查成功前不清除，防止下載／草稿／交易失敗後漏掉更新。自己的已驗證索引變更不重複下載；移除已知索引會重新驗證版本鏈。衝突仍依不可變版本關係與本機基準，不依時間覆蓋。

## 協調、退避與資料

同來源使用`life-system.drive-poll-leader.v1` Web Lock選出一個可用前景分頁；隱藏／離頁釋放，其他前景候選至多約5秒嘗試接手。前景／連線事件也透過同來源BroadcastChannel喚醒既有負責頁，不讓新前景分頁另開重複輪詢。每個實際網路同步仍經既有`life-system.drive-sync.v1`互斥鎖，輪詢／手動／上傳不競爭；輪詢忙碌直接略過，不排隊。領導鎖只在同一瀏覽器來源有效，不是跨裝置鎖。

429、403限額原因、5xx、網路暫時錯誤：10秒起指數退避、±20%隨機延遲，計算上限5分鐘；Retry-After秒數或HTTP日期若更長則尊重。成功回復5秒。專用本機`life-system.drive-retry.v1`只共享下次允許時間及有界退避次數，其他分頁／手動入口也不得越過；不含token、不進同步資料。非暫時錯誤停止自動輪詢，授權失效只提示手動重連、不彈窗。長Retry-After分段使用安全timer範圍，不提早發請求。

資料仍先本機保存、最後修改約3秒後合併上傳，不因5秒輪詢每次寫一份。未同步修改不被雲端直接覆蓋；草稿／焦點／頁籤／捲動與既有維護協調保留。20筆可還原版本／時間排序、衝突頭保護、獎勵及Undo／Redo、金鑰／權杖排除維持。
