# 同步版本保留與跨裝置更新

自動同步的加密版本與套用前本機封存共保留20筆可還原資料，選單依createdAt新到舊、同時刻依穩定ID排序。每次有效同步（包含沒有本機修改的檢查）會清理超額舊快照；不是每三秒建立固定週期檔案，也不是覆寫最新資料。手動備份不刪。

版本頭必須保留；一般情況為1個，衝突可多個。若未解決衝突頭本身超過20個，暫停清理並提示，優先保護另一裝置修改。舊快照移除後不能還原；小型不可變版本索引保留，避免停留在舊基準的離線裝置回來時，誤判版本鏈斷裂或覆寫新資料。孤立的未提交上傳不列入可還原版本，避免清理另一裝置尚未完成的上傳。

只刪同步snapshot-v1清單中且有正式索引的較舊資料，不刪手動備份、未完成上傳或必要索引。清理失敗顯示原因，下次同步重試；部分刪除不破壞索引或正式資料。404代表另一裝置已清除同一舊快照，視為冪等成功。網路或權限失敗時暫時可能超過20筆，不能宣稱已清理完成。

手機完成先正式保存本機，約最後修改後3秒上傳；平板有有效Google授權、相同密碼解鎖、沒有本機衝突／草稿阻擋時，開啟／回前景／恢復連線會自動檢查，持續開啟且健康狀態每60秒補查並套用最新資料。不是即時推播；兩端同時修改會偵測衝突，授權失效需重新連接。

測試：167項單元通過，包括時間排序、20筆上限、舊版祖先索引、封存計數及衝突頭保護。tests/drive-sync-browser.cjs以兩個隔離Chromium+mock Google，實際建立超過20份加密快照，檢查較舊資料刪除、保留列表20筆與排序、舊裝置追上、403清理失敗保留正式資料及重試。原有首次採用、圖片還原、離線、並行衝突、授權失效及autocomplete測試保留。真實Google刪除權限與實體手機／平板同步未驗收。
