# 手機首頁夥伴與導覽

首頁新增事件靠右並直接開共用當日事件表單。手機夥伴預設最上方、可拖曳／鍵盤移動、可收合／展開，不顯示叉叉；首次、重新整理及每次站內回到首頁顯示招呼，首頁行動使用原mock回應，顯示4秒後隱藏。拖曳時暫停計時，放開再計時；離頁取消計時。桌面立繪不變。待辦／習慣沿原完成有效性及獎勵動畫時序，展示時共用同一浮窗與控制。

導覽圖示四目的頁及Undo保留；原Redo位置為最新雲端還原，Redo移至設定歷史紀錄。焦點、44px觸控與底部安全區保留。首頁及待辦主頁籤不自動垂直捲動。

驗證以tests/home-events.cjs、home-cloud-changes.cjs、navigation-retry.cjs及共用導覽／頁框回歸為準；以往常駐逾4秒的測試規則已被取代。

首頁手機操作通知隨選中面板置於新增事件／管理習慣同列，單一DOM保留訊息，切頁籤或打卡重建不遺失。加分摘要只列項目與實際累計點數，入口與管理列緊縮；桌面通知仍在立繪下方。

浮窗位置、收合及計時只留各頁DOM記憶體；拖曳暫停4秒計時，放開重新計時，方向鍵移動與viewport夾限保留。首頁保留招呼，待辦／習慣只顯示本頁有效完成的配對回應，不於返回／Undo／Redo重播。驗證tests/shared-avatar.cjs、mobile-polish.cjs及task-mobile-response-guards.cjs。
