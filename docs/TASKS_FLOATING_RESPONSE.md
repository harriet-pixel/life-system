# 手機待辦浮動夥伴

來源基準main `ea4bcc8`。僅待辦頁`<1024px`移除夥伴正常排版高度；桌面原立繪／對話、首頁與其他頁面不變。Cloudflare暫停。

## 展示時序

沿用同一共享mock控制器及450ms合併、生成、成對情緒／對話邏輯，不新增請求或角色資料。共享view只多帶該回應的action IDs及是否快取重播的唯讀資訊，原首頁callback仍使用同一份reply。

完成流程原子提交後、既有獎勵動畫加入佇列時，發出文件內`completion-presented`展示訊號。手機view只接受本頁活動期間收到的本機成功訊號，以action ID對應已生成的回應；在全部相關完成仍有效、沒有獎勵動畫節點、沒有開啟dialog／鍵盤時顯示。不猜測動畫秒數，不延遲或更改獎勵交易；舊回應不因重新訂閱而浮出。

重用原夥伴DOM，手機平時display:none，顯示才fixed定位。無額外卡片陰影／漸層，沿原對話泡泡、頭像佔位、共用字型與次要文字token。可視viewport定位，底部依首頁共用浮窗與實際導覽邊界（包含安全區）保留間距，浮動不佔流、不移動捲動或焦點；寬度沿首頁頭像與對話可用範圍、兩側至少12px。可換行、長文內捲、CSS縮放與viewport offset均重新計算；不顯示X，頭像本身為至少44px觸控目標，可收合／展開、拖曳及方向鍵移動，約4秒自動消失。一般160ms淡入、reduced-motion無動畫，獎勵仍沿原靜態短提示。

快速連續操作沿共享控制器合併且只顯示一個回應；獎勵仍逐組排隊。新增／編輯／設定／確認dialog打開即收起並丟棄等待回應，關窗不補播；鍵盤同理。取消、交易失敗、刪除完成／撤回、Undo／Redo、跨分頁、重載、離頁／返回不憑舊完成紀錄生成浮動提示；展示前與展示中都驗證長期完成仍有效。

不修改正式資料schema、獎勵算法、鎖、AI分配、Undo／Redo或備份內容。展示map／timer只在記憶體且有界，inactive view移除監聽／observer並清空展示狀態。

## 手機待辦池選單

移除可見X與底部關閉文字，名稱由20px降為1rem（預設16px），保留分類色與四操作2×2。外側pointerdown及click均在dialog外才關閉，從內往外拖曳不誤關；點內部不關閉，Escape及原回焦不變。桌面原文字關閉、字級與選單不改。

## 驗證

`tests/task-mobile-response.cjs`實際計時動畫：320／375／390／430px、1024／1280px，初始無流內空間、獎勵動畫先於回應、捲動不變、導航避讓、四秒自動消失、快速完成合併、取消／Undo／Redo／重載不重播、200%縮放、池外點關閉與拖曳、首頁／桌面回歸。

`tests/task-mobile-response-guards.cjs`驗證減少動態、開窗抑制、模擬visualViewport鍵盤／offset與恢復、焦點、跨頁快取回應不重播。`tests/tasks-progress.cjs`驗證AI mock延遲／無效／網路錯誤／過期結果／配額寫入失敗及跨分頁競爭只有成功端浮出。

真實手機鍵盤與iOS Safari未驗收；AI及夥伴使用mock，不宣稱正式角色服務已串接。
