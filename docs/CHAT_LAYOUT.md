# 首頁招呼、聊天室與夥伴通知調整

2026-11-02；原始碼基準遠端main `767fb90`。使用原有dataStore、角色／聊天服務、共用AI、原生dialog與頁面lifecycle。

- 首頁一律使用夥伴頁儲存的四時段三句設定，沿既有輪播與留白預設；不自動呼叫AI，不加未連線括弧。設定中的星光生成可明確產生草稿，仍須保存才生效。正式生活回應的AI不變。
- 聊天失敗回合的手動生成／本機恢復提交用44px無框SVG，置於訊息框外左側，保留aria-label／title及原retry的回合ID、共用鎖、有效來源、busy及防重複計分。已完成回合不新增重送入口。已驗證結果仍只恢復本機提交，不重送AI。
- 訊息時間與狀態移到框外下方；角色情緒頭像、完整文字與安全textContent維持。輸入框只顯示「輸入訊息」，maxlength仍800；Enter送出、Shift+Enter換行、IME不誤送維持。移除聊天室取消生成按鈕與下方共用AI說明；離頁／換角色／epoch變化仍由控制器取消及拒絕遲到回覆，草稿不刪除。
- 夥伴一般操作、設定、草稿、聊天錯誤及站內路由通知統一頁首operation-status，同一DOM於桌機標題下或手機兩行通知第二行顯示，不在聊天輸入區／角色設定區／頁尾重複。訊息逐筆時間與狀態保留於訊息下；回覆庫容量等資料摘要不當作操作通知，dialog欄位錯誤仍留在modal內，避免鍵盤與輔助工具使用者失去錯誤原因。原本新增角色的alert改頁首通知。
- 永久刪除角色先說明資料影響，再彈出第二次確認；不要求輸入名稱。取消任一次不刪除。捕捉所選角色ID，出場者在同一正式交易取消出場；tombstone、來源參照、好感度與歷史／備份政策沿原服務。
