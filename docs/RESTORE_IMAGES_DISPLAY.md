基準：最新遠端main 685b250，gh-pages c50539d；原始碼工作區原為乾淨狀態。保留唯一dataStore、現有圖片DB、共用鎖／revision、5筆手動雲端政策與還原vault，未啟用後端或同步。

## 圖片還原選項評估與行為

本機／雲端還原視窗提供「此次匯入備份圖片」，每次開窗預設不勾選；取消／關閉後不沿用上次選擇。該選項控制圖片檔匯入，圖片選用設定仍依所選備份還原，不是以不同本機圖片任意替換備份引用。

未勾選時：使用本機相同內容ID的資產。所選文件及仍有效Undo所需的任何圖片缺少，則在任何正式替換與vault／回覆庫／聊天暫存前停止，保留原primary、圖片、檔案、勾選與已驗證內容，提示勾選後重試。缺圖不自動清空設定，不丟棄復原鏈。

勾選時：只匯入缺少的圖片；既有同ID檔案不覆寫。兩種模式都檢查必要資產的內容雜湊／MIME與角色比例等完整性，本機同ID損壞則停止，不用備份悄悄覆蓋。確認期間revision變動同樣停止。API預設保留既有完整還原相容行為，各正式UI明確傳入當次勾選值。

這個選項適合作為還原控制；它不等同跨版本雲端圖片去重。原圖片DB已按內容ID只存一份，同ID已不會重複寫入bytes。完整備份仍自包含所有必要圖片，雲端仍整檔下載及驗證；選項不會減少上傳量或省略安全驗證。真正減少跨版本圖片上傳仍需要獨立資產manifest及跨版本引用清理方案，本次未實作。

## 貨幣與空白對話

所有既有數據列由profileSummary共用輸出：`$170 / 200`。兩值沿現有formatSI：10000→10K、1500→1.5K、1234567→1.2M，1000進位，至多一位小數；0仍顯示0。儲存仍為完整非負安全整數，不改帳本逐筆金額、表單或交易計算。首頁／共用daily-header／資料頁／錢包桌面列的aria-label與title保留目前及累積貨幣完整整數。

待辦／習慣／錢包初始對話空白；CSS依對話內容是否為空隱藏整個bubble（邊框／內距／三角一併隱藏）。正式回應非空立即沿原樣式顯示，清空後隱藏。立繪與既有手機浮窗生命週期不變，不新增監聽、輪詢、AI或資料操作。
