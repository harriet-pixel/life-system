# 首頁設定招呼與升級提示

2026-11-02更新：依使用者最新指示，撤回首頁自動AI招呼，改為一律使用夥伴頁設定。

首頁進入／返回依當前正式出場者、臺灣四時段及session索引輪播三句已保存招呼；舊單句仍能讀取，留白用既有預設。不因AI連線、忙碌、失敗或好感度不同而生成，不加「AI尚未連線」。移除專用自動首頁生成模組；角色設定星光按鈕仍可明確產生十二句草稿，手動儲存才改設定。首頁正式生活操作的既有AI回應不變。

使用者跨級顯示「等級提升至Lv.{N}」；好感度跨關係等級顯示「好感度提升至Lv.{N} {階段名}」。一般好感度增減不跳動畫；沿原共用佇列與減少動態效果。

目前測試與聊天室／通知／刪除確認規範見[CHAT_LAYOUT.md](CHAT_LAYOUT.md)。原374項測試中的5項自動首頁AI測試隨功能移除，目前369項單元測試及首頁永不自動請求AI的瀏覽器回歸取代。
