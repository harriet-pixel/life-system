# 首頁AI招呼及升級提示

2026-11-02，原始碼基準遠端main `0644f48`。

首頁進入／返回時由當前正式出場、未封存角色透過getSharedAIConnection最多生成一次首頁招呼；同次頁面resume與訂閱的觸發合併，無重複請求。首頁模組才載入服務，不讓其他頁面預載／背景提示自行生成。

提示沿compactPersona、boundedPrompt及全站AI語言規則，包含臺灣Asia/Taipei當前日期時間與時段、角色必要人格、好感度數值、當前關係階段名稱及其態度／行為／界線。其他角色、聊天、待辦、習慣、帳本及使用者完整資料不送。單次128輸出、沿正式回覆解析；呈現完整文字，不加省略號、不產生記帳、好感度、成長獎勵或行動紀錄，也不改已保存的招呼。

未連線、忙碌、失敗或格式無效使用夥伴頁保存的四時段三句備援，依既有session索引輪播；留白用原預設，末尾加「（AI尚未連線）」。等待期間先顯示備援，成功後以AI文字取代；忙碌不排隊或搶占其他AI，失敗不自動重試。星光生成十二句的功能仍只編輯備援草稿，明確儲存才改正式設定；備份與版本規則不變。沒有有效角色不發AI請求。

失效保護比對characterId、createdAt、configVersion、人格投影、好感度、封存／出場、switchHistory與還原epoch，並驗證當天時段。離頁、明確關閉／10秒收起、角色或還原失效均取消尚屬本次的AI請求；失效不因後續狀態改回而復活。正式生活操作回應開始立即讓首頁招呼失效並釋放本次請求，遲到招呼不得覆蓋正式回應。不持資料鎖等網路，不在同步或還原時補發招呼。

動畫沿原共用佇列：使用者跨級顯示「等級提升至Lv.{N}」；好感度跨關係等級顯示「好感度提升至Lv.{N} {階段名}」，如「好感度提升至Lv.2 熟悉」。普通好感度增減不顯示動畫；減少動態效果改靜態文字。只改文案，不改正式數值或來源。
