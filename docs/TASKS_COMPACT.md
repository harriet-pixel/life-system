# 待辦版面與全域清單設定

來源基準：遠端 main `e8c6c4ae800025298bf9e26416148abd6c03c954`。沿用原生模組、資料交易、共用頁籤底線與按壓回饋；Cloudflare 暫停。

## 頁面與視窗

- 日期旁僅保留無框＋，不顯示單日清單設定；原有完成方框與事件選單不變。
- 待辦池三區標題20px級／700粗體；第一區上方及三區之間用單條細線，內容仍有1em內縮。
- 手機移除可見黑色標題，保留sr-only頁面標題。原本的任務看板數量與operation-status同一DOM節點移到頁首，兩者各一行且固定保留兩行高度，月曆／設定44px按鈕在右且無框；不複製資料或通知。移除手機夥伴區上方線條及重複標題下緣留白，桌面立繪與通知位置不變。
- 一般操作通知最多10個Unicode code points，由operation-notice統一縮寫；完整原文保留title及aria-description。完成、取消、撤回、相依／過期／儲存等仍有對應短提示；先辨識成功／等待前綴，避免事件名稱含「失敗／取消」時誤判。表單與modal的詳細錯誤、夥伴對話不截斷；其他頁面通知不縮短。共用路由在待辦頁的操作結果也走同一入口。
- 待辦事項設定有新增事件／管理分類／清單設定三頁籤，桌面可從新增的「待辦事項設定」入口開啟，原新增與管理分類入口保留。設定窗內移除新增事件取消與分類清單關閉，右上統一無框SVG叉叉；獨立分類編輯與一般編輯仍保留自己的取消／返回流程。固定可用視窗高度、內捲、keyboard focus與草稿保留不變。

## 全日期共用設定

`tasks.views.list` 可選欄位包含sort／direction／spacing，與舊日期設定使用相同枚舉。不存在時採建立時間升冪、緊密行距（已儲存設定維持）；不猜測多個舊日期設定哪個應成為全域值。舊`views.dates`保留於資料與快照，但不再影響呈現，新全域值適用今天／其他日期／歷史清單，含尚未瀏覽的日期；不預建日期設定。

`listSetting`經原共用交易／revision／鎖驗證，只有呈現設定變更，不更動事件定義順序、日期或數值；驗證、舊備份相容、備份還原、跨分頁及Undo／Redo一併涵蓋。儲存時防重送並暫停欄位，失敗保留輸入；成功顯示「設定已儲存」，手機關窗、桌面留窗；切頁籤仍保留草稿。使用右上叉叉離開。

不再提供每日批量完成／刪除介面。既有批次完成／撤回交易的歷史驗證、備份及服務方法保留，不能因此破壞既有完成紀錄或Undo；待辦池逾期批次安排／不再處理不受影響。

## 日期新增選取

三頁籤仍是新增事件／重複性事件／任務看板，取消與成功關窗／回日期＋規則維持。移除頁籤數量徽章、重複日期提示、說明段落、分類後數量、名稱後灰分類與可見已安排字樣；下方總已選筆數與確認／清除仍保留。

分類標題與事件名稱沿分類色，未指定或無色用原預設文字色。名稱14px級、700粗體、無框；選中以底線與aria-pressed表達，鍵盤焦點框保留。既有日期／例外／期限外仍停用，必要原因保存為aria-description，沒有靜默復活或延長期限；完整名稱title保留。事件分隔仍是「 ｜ 」，換行行首隱藏，分類分組收合不丟選取。

三個頁籤名稱16px級、日期標頭20px級；窄螢幕可換行，鍵盤模式仍按可用高度避讓。開始／結束日期、同日唯一性、分類資料與原子安排交易完全沿用。

## 設定頁

直接初次進入settings.html時所有settings-disclosure均收合（外觀、AI、備份、儲存、歷史）。使用者自行展開與站內返回仍保留當前狀態；明確的舊連結／錨點如#ai、#history仍可開啟指定區塊。短內容不額外製造空白捲動區，頁籤定位可在文件捲動邊界自然clamp。
