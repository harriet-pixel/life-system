## 修正

1. 桌面立繪與手機頭像：角色設定CSS的`.character-image-view { position:relative }`與日常圖片層具有同等優先序，跨頁載入順序會覆寫定位。日常CSS改為明確擁有者選擇器，固定絕對定位與滿框尺寸，覆蓋範圍只在日常立繪內；avatar圖片inset不再依不定的靜態位置。滿框3:4、原圖裁切、neutral備援、有限URL釋放保持不變。共用view初始化明確toggle avatar class，避免由手機切桌面仍圓形裁圖。
2. 三頁手機浮窗由4秒改10秒；新增圓形頭像右上方獨立關閉SVG按鈕，44px觸控範圍，點擊不觸發頭像收合／拖曳／資料寫入。長對話較高時仍錨定頭像右上角，不浮到對話頂端。保留既有收合、拖曳、方向鍵、鍵盤與safe area避讓。
3. 只有首頁保留進入／返回招呼。待辦與習慣首次、重載、切換／返回均不因招呼而浮出；正式完成、撤回、數值變動與Undo／Redo回應保留。
4. 三頁手機浮窗最多40個可見字元，超長取39字加省略號；以grapheme避免切斷組合emoji／變音符號。僅顯示層有界處理，不修改儲存招呼／回覆庫／AI資料。轉桌面還原完整文字，不新增AI請求或Token。
