# 共用頁面外框與設定分類

2026-10-23：保留三份原生 HTML 與網址，新增 `assets/app-shell.mjs` 的漸進式站內導覽；不新增框架、網站或伺服器 rewrite。

## 路由與直接連結

- 首頁 `/life-system/`（或 index.html）、profile.html、settings.html 都可直接開啟／重新整理，適用 GitHub Pages 專案子路徑。
- 一般同來源、已實作頁面的無修飾左鍵／Enter 連結由 History API＋靜態 HTML fetch 更新主內容。共用桌面／底部導覽與 Undo／Redo 元件只初始化一次，保留其 DOM 與本機資料服務。
- Ctrl／Cmd／Shift、右鍵、另開分頁、download、外部網址仍遵守一般 anchor 行為；未實作功能不建立假目的頁。頁面載入失敗保留原頁及草稿，供重試，不自動整頁刷新。
- 更新 document.title、作用中 aria-current，切頁焦點至主內容（不框住整頁）；上一頁／下一頁以各歷史 entry 保存的實際捲動及仍存在的焦點還原。新頁通常頂端；明確 fragment／舊設定定位則開啟對應區塊。
- HTML 具有 shell 版本標記，跨版本不拿新 DOM 配舊掛載程式。入口、變更的下層模組與樣式都更新 cache query；保留資料模組的單一 URL 身分。

## 草稿與生命週期取捨

三個已實作頁面的內容 DOM 最多各保留一份於本文件記憶體；非目前頁面從 document 移除，不保留隱藏的重複 ID／可操作或可存取內容。不序列化輸入、密碼、圖片草稿或 API key 至一般儲存。這是有界的 DOM／影像記憶體取捨，以保留未提交輸入，不是保證重新整理後能恢復所有草稿。

`page-lifecycle.mjs` 統一 suspend／resume：
- 頁面模組只 mount 一次，DOM-local 事件隨草稿保留；離開時取消資料／AI 訂閱、全域事件及量測觀察，返回才重掛。首頁 mock 等待與頁籤定位 frame 在離開時取消。
- 使用者資料／圖片視窗與其多層 dialog 暫停後可恢復；暫停的 close 事件不執行「取消草稿」流程，原來真正儲存／取消行為不變。
- 尚未保存的資料／外觀草稿仍持有原 draft lock，避免另一頁備份、還原或清理誤用未完成資料。需要先返回原處儲存或取消時會沿用具體提示，不偷偷丟棄草稿。
- 真正離開文件／重新整理，僅有未保存或未送出輸入才提示；站內路由因保留草稿而不另外要求確認。原 pagehide 的憑證、密碼及圖片 URL 安全處理保留，不宣稱 sessionStorage／記憶體能絕對抹除。
- 已提交資料始終來自同一 dataStore；恢復訂閱時讀取最新值，不能用舊 DOM 覆寫保存內容。儲存管理依資料修訂失效快取，使用者重新展開／重新檢查時重讀並保留仍可選的選取，不在每次資料變動背景取得維護鎖與還原競爭。

## 共用 AI

同文件一個 AI runtime，站內切頁不重新建立連線或清空模型，直連不自動到期；收合／分類切換不清除輸入。使用者主動離開處理中的 AI 頁面時，共用服務取消並使舊結果失效，面板的 request sequence 也失效；不將遲到回覆寫入新頁或自動重送。已送到官方的請求仍可能計費，取消不保證退款。

真正重載仍依原 session 規則恢復，第一次主動生成前重新查模型。繁體中文共用提示不變；未定義的夥伴／分點仍為 mock。Cloudflare 本次暫停，不建立或部署服務，原 Node／Worker 原始碼、正式模式與直連備用都保留。

## 設定頁

最上層兩個頁籤：
- 一般設定（預設）：外觀設定、AI 連線。
- 資料管理：備份與還原、儲存空間、歷史紀錄。

每項使用原生 details／summary，可獨立展開與收合、鍵盤操作，不增加子頁籤列。原控制項及歷史每頁五筆的操作保留；分類／收合不重建表單。AI 收合摘要區分暫存 key、查詢／選取模型、生成成功／取消／錯誤，不籠統寫已連線，不含憑證。

舊定位 `#appearance`、`#ai-tab`、`#backup-panel`、`#storage-section`、`#history`，以及 `?tab=ai`／`?section=history` 都對應至新分類並開啟區塊。

## 定位與尺寸

- ≤450 CSS px 點擊內容頁籤才定位；>450 只切內容。點擊當下判斷，縮放／旋轉立即生效。尊重減少動態、固定列與底部導航避讓，限制於實際可捲動範圍。
- 首頁待辦／打卡仍以兩者當下較大高度共同量測；不複製可操作內容。設定「資料管理」維持頂端定位，歷史不置中。details toggles 不呼叫頁籤定位，並取消尚未執行的定位 frame；資料／字型／非同步更新不另定位。
- 導覽沿用 1024px 桌面斷點，按實際高度分 comfortable（>600）、compact（421–600）、tight（≤420）。先減上下 padding／圖示間距，tight 才將手機 .875rem 小幅調為 .8125rem；按鈕至少 44px。
- 文字項目可局部水平捲動，Undo／Redo 不縮小。使用者字型、200% 文字及安全區不變。
- editable 焦點期間的顯著高度縮減視為鍵盤，保留原密度／字級，以 visualViewport 避讓及最小必要捲動保持輸入可見；旋轉造成寬度變化重新計算。pinch scale 不誤判鍵盤。實體手機鍵盤／瀏覽器政策仍需實機驗收。

## 驗證

- app-shell.cjs：同 document／導覽 DOM、三頁反覆切換、草稿及視窗、直接 URL／重載、前後頁、捲動、新分頁、單次交易與 Undo／Redo。
- shell-ai.cjs、ai-browser-mode.cjs：mock 的共用連線、模型快取、跨頁、收合摘要、取消競態、不重送、重載、原始期限。
- settings-tabs.cjs：32 組尺寸／字型、450／451、鍵盤、旋轉、200% 文字、收合及非同步無定位競爭。
- navigation-responsive.cjs：10 組寬高、觸控範圍、模擬鍵盤；首頁動態共同高度與定位邊界。
- settings-cache.cjs、ai-cache.cjs：精確舊 revision 暖快取升級，不清資料。
- 其他首頁、導覽、照片／裁切／最愛、備份／還原、歷史、Undo／Redo 及資料單元／瀏覽器腳本持續回歸。

mock 不代表真實 API／所有裝置已通過。使用者僅已回報 DeepSeek 直連連線成功，不能擴大為本次生成／跨頁或其他 provider 驗證。Pages 推送、部署 workflow 與公開站實測分開回報。
